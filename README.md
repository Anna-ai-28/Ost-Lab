# Git and GitHub Basics

## Description
This project is created to understand the basics of Git and GitHub.  
It demonstrates how to create a GitHub account, initialize a repository,  
and push a README file to GitHub using basic Git commands.

## Objectives
- Learn what Git and GitHub are
- Create and manage a GitHub repository
- Understand basic Git commands
- Push files from local system to GitHub

## Tools Used
- Git
- GitHub
- Command Line / Terminal
